# PriceSmart AI — UI Page Structure (Phase 1)

## 1. Route Map

| Route                          | Page                    | Auth Required |
|----------------------------------|---------------------------|-----------------|
| `/login`                         | Login                      | No              |
| `/register`                      | Register                   | No              |
| `/`                               | Dashboard                  | Yes             |
| `/products`                       | Product Management (list)  | Yes             |
| `/products/:id`                   | Product Details             | Yes             |
| `/products/:id/recommendation`    | AI Price Recommendation     | Yes             |
| `/products/:id/forecast`          | Demand Forecasting           | Yes             |
| `/products/:id/competitors`       | Competitor Analysis          | Yes             |
| `/analytics`                      | Analytics                    | Yes             |
| `/reports`                        | Reports                      | Yes             |
| `/settings`                       | Settings                     | Yes             |

All authenticated routes render inside a shared `DashboardLayout` (Sidebar + Navbar + content outlet), guarded by a `ProtectedRoute` wrapper that checks the JWT in `AuthContext`.

## 2. Page-by-Page Breakdown

### Dashboard (`/`)
- KPI cards: total products, avg margin, revenue this month, active AI recommendations
- Recharts: price trend line chart, demand bar chart
- Recent price changes table
- Quick links to Products / Reports

### Product Management (`/products`)
- Searchable/filterable product table (category, stock, price range)
- "Add Product" modal/form
- Row actions: view, edit, delete, request AI recommendation
- Pagination

### Product Details (`/products/:id`)
- Product info panel (editable)
- Price history chart (Recharts line chart)
- Tabs or quick-nav to: AI Recommendation / Demand Forecast / Competitor Analysis for this product

### AI Price Recommendation (`/products/:id/recommendation`)
- Current price vs recommended price comparison card
- Confidence score indicator
- "Apply Recommendation" action → writes to price history
- Explanation panel (factors: cost, competitor spread, demand signal)

### Demand Forecasting (`/products/:id/forecast`)
- Forecast period selector (daily/weekly/monthly)
- Recharts forecast chart (predicted demand & revenue)
- "Generate New Forecast" button
- Forecast history table

### Competitor Analysis (`/products/:id/competitors`)
- Competitor price table (add/edit/delete entries)
- Price positioning chart (your price vs competitor range)

### Analytics (`/analytics`)
- Cross-product KPI overview
- Price trend and demand trend charts, filterable by category/date range

### Reports (`/reports`)
- List of generated reports (type, date range, generated by)
- "Generate Report" flow (choose type + date range)
- Download/export action

### Settings (`/settings`)
- Currency, default margin, AI auto-apply toggle
- Notification preferences
- Account info

## 3. Shared Component Inventory (planned for Phase 3)

- `Navbar`, `Sidebar`, `DashboardLayout`
- `Button`, `Card`, `Modal`, `Loader`, `Badge`, `Table`
- `PriceChart`, `DemandChart`, `TrendChart` (Recharts wrappers)
- `ProtectedRoute`, `AuthContext`
- `ProductForm`, `ProductTable`

Framer Motion is used for page-transition fades and card/list entrance animations throughout — no layout logic depends on it, so it stays purely presentational.
